# MILU — доставка гастробоксов

Адаптивный промосайт для вымышленного бренда MILU — закуски, гастробоксы и десерты с доставкой по Саратову.

## Структура
- `index.html` — семантическая разметка сайта
- `css/style.css` — стили, адаптивность и анимации
- `js/script.js` — каталог, фильтры, поиск, избранное и корзина
- `assets/images/` — папка для локальных изображений

## Запуск
Откройте `index.html` в браузере. Сборка и сервер не нужны.
